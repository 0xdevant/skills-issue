# Clarity pitfalls

Independent of register and medium. These are ways a sentence can be correct Cantonese and still
land wrong.

## Ambiguous idioms

An idiom that reads two ways will be read the wrong way by someone.

```
✗ 幾歲人都可以中招
   Reads as "people of any age — including children". Rarely the intended meaning.
✓ 識嘢都中招 · 老貓燒鬚
```

Before keeping an idiom, ask what it says literally to someone who doesn't know it.

## Second meanings

Check the other reading before you keep the joke.

```
✗ 搞掂佢哋，不如搞掂自己
   「搞掂自己」 reads as "finish yourself off". Self-harm connotation.
✓ 搞到自己咁辛苦，不如一次過整好佢
```

Especially worth checking: anything about death, bodies, money, or family.

## Acronyms and obscure names

If a general reader wouldn't recognise it, **describe what it does** instead of naming it:

```
✗ 佢哋用 TDS 判斷你係咪目標
✓ 佢哋識得判斷你係咪目標用戶

✗ 用 Ghidra、dnSpy 拆解個 app
✓ 用熱門逆向工具拆解個 app
```

The specific name belongs in the source link, for the few readers who want it. Naming it in the
body costs every other reader a stumble.

Same for jargon that has a plain equivalent — 「正版嘢」 beats a technical verification term in a
fake-vs-real context.

## Precision about who did what

Cantonese drops subjects easily, which is natural in speech and dangerous in reporting.

```
「佢被中招」  ← does this mean he was impersonated, or that he fell for it?
```

If a sentence assigns blame or victimhood, name the actor explicitly. Getting this wrong in a news
post is a factual error, not a style one.

## Numbers and dates

- Write dates the way HK writes them: 「9月1號」, not 「1/9」 (ambiguous) or 「September 1」.
- Keep a figure's units attached: 「成萬四 star」 not 「14000」 floating.
- If a number is the point of the sentence, put it at the end where it lands.

## Over-compression

Cantonese compresses well, and it's tempting to keep squeezing. Past a point the reader has to
decompress it, which is slower than reading a slightly longer sentence. If a line needs a second
pass to parse, expand it.
